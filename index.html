Daily Job Discovery & Application Routine

SOP · 20-Min Daily Habit

A simple, 20-minute daily habit designed for fresh graduates and busy professionals. Instead of spending 4 hours scrolling job boards and sending 50 generic resumes that get ignored, you find 2 high-matching vacancies every morning, verify you can actually do the job, and generate 100% tailored, ATS-ready application packages before 08:20 AM.

Routine Clock 08:00 AM
Elapsed 00:00 / 20:00
Speed:
Stage 1 08:00 - 08:05

Spot Fresh Jobs & Skip Old Ones

Find 10–15 newly posted openings from the last 24 hours. Automatically filter out companies you already applied to so you never send duplicates.

  • Step 1: Check Application History — Scan your simple tracker (jobs/job_matches.md) to instantly eliminate any company or role you already applied to.
  • Step 2: 1-Click Search Sweeps — Open pre-filtered Google, LinkedIn, StepStone, and startup links to uncover active vacancies posted today.
Stage 2 08:05 - 08:10

Check Your Fit & Pick The Top 2

Don't waste time spraying 50 random applications. Grade vacancies from 0 to 10 and only focus on roles you are actually qualified to win.

  • Step 3: Grade Your Fit (9/10 Rule) — Score required skills (70%) vs nice-to-haves (30%). Disqualify jobs with impossible dealbreakers (e.g. 10 years experience).
  • Step 4: Save Job Details & Check Pay — Save the full job description text before it expires, and check typical salaries on Kununu or Glassdoor to verify fair compensation.
Stage 3 08:10 - 08:15

Auto-Generate Resume & Cover Letter

Stop spending 3 hours manually editing Word files. Let automation create custom, ATS-friendly application packages in seconds.

  • Step 5: Tailored ATS Resume — Generates a clean, ATS-compliant resume highlighting the exact projects and skills the employer asked for — zero formatting bugs.
  • Step 6: DIN-5008 German Cover Letter — Writes a punchy, 1-page cover letter (<300 words) solving 3 key employer problems with real proof, then exports to crisp PDF.
Stage 4 08:15 - 08:20

Submit, Record It & You're Done!

Upload your PDFs directly to the employer's official website, log the date in your tracker, and finish before morning coffee.

  • Step 7: Log in Application Tracker — Add the company name, apply link, and date so you always know when to follow up and avoid messy spreadsheets.
  • Step 8: Close Your Laptop & Relax — 2 top-tier, custom applications dispatched in under 20 minutes. Zero burnout, maximum interview callbacks!

Get Started in 4 Steps

About 30 Minutes · Once

From download to an automatic morning run. You need Python 3.10+ (no extra packages), Chrome or Edge for PDF export, and an AI coding agent for steps 3 and 4. The examples use Claude Code; Codex CLI and Gemini CLI read the same AGENTS.md and work the same way.

On macOS and Linux, type python3 wherever the commands say python.

  1. 1

    Install

    Clone the repository (or download the ZIP and unzip it), then build the example resumes to check that Python and the PDF export work. You should get PDFs in jobs/roles/pdf/.

    Clone and test the engine
    git clone https://github.com/masrisystems/career-engine.git cd career-engine python jobs/engine.py build-roles
    Optional: only preview the web pages
    Serves this page and the web resume at http://localhost with Docker. Port 80 taken? Prefix with PORT=8080.
    docker compose up --build
  2. 2

    Create your profile with AI

    Everything the engine writes (resume, cover letters, search links) comes from one file: config/profile.json. Let an AI fill it for you:

    • Copy the Profile & Resume Onboarding prompt into ChatGPT, Claude or Gemini.
    • Paste your old CV or LinkedIn text after it, or type Interview me to answer 7 short questions instead.
    • Save the JSON it returns as config/profile.json, replacing the example.
    • Rebuild with your data and open the results: your resume PDFs in jobs/roles/pdf/ and your job board links in daily-job-search-links.md.
    Build from your profile
    python jobs/engine.py build-links python jobs/engine.py build-roles
  3. 3

    Do your first daily run with your AI agent

    Open a terminal in the career-engine folder, start your agent (claude, codex or gemini) and paste the instruction below. The agent searches for jobs, scores them, writes a tailored resume and DIN-5008 cover letter for the best matches with jobs/engine.py, logs them in jobs/job_matches.md and ends with a Morning Action Brief like the example below. Watch this first run and approve its steps, so you know what the scheduled run will do.

    Paste into your agent
    Read AGENTS.md, skills/daily-job-workflow/SKILL.md and daily-job-search-workflow.md, then run today's daily job workflow exactly as described there. Find up to 2 open roles that score 9.0/10 or higher, build each application package with python jobs/engine.py, update jobs/job_matches.md and finish with the Morning Action Brief. Prepare only: never submit an application or contact an employer.

    Read the packages in jobs/resumes/ and jobs/cover_letters/, fix anything that is wrong, and send the application yourself. The agent never applies on your behalf.

  4. 4

    Schedule it every weekday morning

    scripts/daily-run.ps1 (Windows) and scripts/daily-run.sh (macOS, Linux) run the same instruction through Claude Code without a chat window. The agent may only read and edit files in the project, search the web and run jobs/engine.py. Each run writes a log to jobs/logs/. Schedule the script for 07:30, then spend your 20 minutes reviewing the packages instead of searching. Replace the example path with your own folder. Your computer needs to be on at that time.

    Windows (Task Scheduler)
    Run once in a terminal. Remove it again with: schtasks /Delete /TN CareerEngineDaily
    schtasks /Create /TN CareerEngineDaily /SC WEEKLY /D MON,TUE,WED,THU,FRI /ST 07:30 /TR "powershell -NoProfile -ExecutionPolicy Bypass -File C:\career-engine\scripts\daily-run.ps1"
    macOS / Linux (cron)
    Run crontab -e and add this line. Remove the line to stop.
    30 7 * * 1-5 $HOME/career-engine/scripts/daily-run.sh
    Cloud (Claude Code routine)
    Runs even when your computer is off. Push your copy to a private GitHub repository (it contains your profile), then type this in Claude Code and give it the step 3 instruction and a weekday 07:30 schedule.
    /schedule

Profile & Resume Onboarding

Fast Track

Ingests an existing resume (PDF/text/LinkedIn) or runs a guided 7-question interview to generate config/profile.json and tailored STAR bullets.

# Rolle: Principal Career Architect & ATS Engineer # Input: Lebenslauf einfügen ODER 7 geführte Fragen beantworten # Output: Vollständiges config/profile.json + STAR-Erfolge (DE/EN)
# Rolle & Persona
Sie sind ein leitender Technical Recruiter, Principal Career Architect und Experte für ATS-Systeme (Applicant Tracking Systems) im DACH- und internationalen Raum. Ihre Aufgabe ist es, einen Kandidaten schnell und schlüsselfertig in das Open-Source "Career Engine" System einzuarbeiten.

# Ziel
Übernehmen Sie die vorhandenen Daten des Nutzers (entweder durch Text-/Dokument-Upload seines bisherigen Lebenslaufs ODER durch ein geführtes 7-Fragen-Interview) und generieren Sie:
1. Eine vollständige, valide Konfigurationsdatei: config/profile.json (Single Source of Truth, exakt nach dem Schema von @config/profile.example.json).
2. Professionelle, zweisprachige (DE/EN) STAR-Erfolgs-Bullet-Points (Situation, Task, Action, Result) mit quantifizierbaren Kennzahlen für den Master-Lebenslauf (index.html).
3. Korrekte vertragliche Invarianten (Kündigungsfrist, Gehaltsvorstellung im DIN-5008-Format).
4. Die exakten CLI-Befehle, um das System zu starten und sofort die ersten PDFs zu kompilieren.

---

# Modus-Erkennung (Automatische Weiche)

PFAD A (Lebenslauf vorhanden):
Wenn der Nutzer seinen bisherigen Lebenslauf bereitstellt (Text, Markdown, LinkedIn-Export oder PDF-Inhalt), extrahieren Sie alle Stationen, formulieren Sie passive Aufgaben in messbare STAR-Erfolge um und erzeugen Sie direkt das vollständige config/profile.json.

PFAD B (Geführtes Interview):
Wenn der Nutzer keinen Lebenslauf hat oder um Unterstützung bittet, stellen Sie diese 7 strukturierten Fragen:
1. Name & Kontakt (Name, E-Mail, Telefon, Ort, GitHub/LinkedIn/Portfolio).
2. Zielrolle & Titel (Englisch und Deutsch).
3. Tech Stack & Kernkompetenzen (6-10 Schlüsseltechnologien).
4. Bisherige Stationen (letzte 2-3 Positionen und Schwerpunkte).
5. Erfolge & Kennzahlen (messbarer Impact: Ladezeit, Team, Umsatz, Nutzer).
6. Vertragliche Invarianten (Gehaltsvorstellung z. B. 65.000 € brutto/Jahr, Kündigungsfrist z. B. 3 Monate zum Monatsende).
7. Suchpräferenzen (Zielort, Radius in km, Remote-Präferenz).

---

# Ausgaben:
1. Vollständiger, syntaktisch valider JSON-Code für config/profile.json.
2. Vorher-Nachher-Vergleich der STAR-Leistungsverbesserungen.
3. Start-Befehle für das Terminal:
   python jobs/engine.py build-links
   python jobs/engine.py build-roles
   python jobs/engine.py validate-resume --file index.html

DIN-5008 Cover Letter

Generates a tailored German tech cover letter using the STAR method, verified project metrics, and DIN-5008 compliance.

# Rolle: Tech-Recruiter & Werbetexter # Aufgabe: Maßgeschneidertes Anschreiben für {{COMPANY}} # Struktur: STAR-Hook, 3 Kernprobleme lösen, Tech-Stack quantifizieren
# Rolle
Handeln Sie als fachkundiger Tech-Recruiter und professioneller Werbetexter mit Spezialisierung auf Anschreiben für Entwickler.

# Aufgabe
Lesen Sie das Kandidatenprofil (@config/profile.json), den Basis-Lebenslauf (@index.html) sowie die kanonischen Rollenprofile (@jobs/roles/*.json). Ich werde Ihnen eine spezifische Stellenbeschreibung zur Verfügung stellen. Ihre Aufgabe ist es, ein hochgradig maßgeschneidertes, überzeugendes Anschreiben zu verfassen, das den Hintergrund des Kandidaten perfekt mit den Anforderungen dieser Rolle in Einklang bringt.

# Anweisungen
1. Reale Projekterfahrungen nutzen: Ziehen Sie konkrete Architekturen, Tools, Performance-Erfolge und Projekte aus @index.html und den Rollendefinitionen heran, um authentische, überprüfbare Beweise für die Fähigkeiten zu liefern.
2. Kein Roboter-Ton: Das Anschreiben darf NICHT wie eine generische KI-Vorlage klingen. Vermeiden Sie typische KI-Buzzwords, Klischees oder übertrieben formelles Füllmaterial. Der Ton soll selbstbewusst, professionell und authentisch enthusiastisch sein.
3. Starker Aufhänger (Hook): Beginnen Sie das Anschreiben mit einem fesselnden ersten Absatz, der sofort die Aufmerksamkeit weckt, die angestrebte Rolle nennt und die relevanteste Qualifikation für genau dieses Unternehmen hervorhebt.
4. Bedürfnisse adressieren: Identifizieren Sie die 3 wichtigsten Anforderungen oder Kernprobleme aus der Stellenbeschreibung. Nutzen Sie den Hauptteil, um präzise zu zeigen, wie die bisherige Erfahrung diese Probleme löst, und quantifizieren Sie den Impact.
5. Kern-Technologien hervorheben: Betonen Sie gezielt die im Profil definierten Kerntechnologien sowie Enterprise-DevOps (Docker, CI/CD).
6. Kompakt & Prägnant: Halten Sie das Anschreiben kurz, überzeugend und strikt unter 300 Wörtern (maximal 3-4 Absätze).
7. Handlungsorientierter Schluss: Enden Sie mit einem starken Call-to-Action und der klaren Motivation für ein persönliches Kennenlernen.
8. Automatisierung: Speichern als JSON-Konfiguration in jobs/configs/JJJJ-MM-TT_[slug].json zur Kompilierung mit python jobs/engine.py run --config ...

ATS Resume Tailoring

Injects target job keywords, sharpens experience bullet points, and maintains strict DOM structure parity.

# Rolle: ATS-Optimierungs-Experte # Aufgabe: Lebenslauf passgenau auf Stellenbeschreibung zuschneiden # STRIKT: Exakte DOM-Struktur von @index.html und Zweisprachigkeit beibehalten
# Rolle
Agieren Sie als Experte für technisches Recruiting, professionelles Schreiben von Lebensläufen und ATS-Optimierung (Applicant Tracking System).

# Aufgabe
Lesen Sie das Kandidatenprofil in @config/profile.json, den Master-Lebenslauf in @index.html sowie die kanonischen Rollen in @jobs/roles/. Ich werde Ihnen eine spezifische Stellenbeschreibung zur Verfügung stellen. Ihre Aufgabe ist es, den HTML-Lebenslauf passgenau auf diese Stellenbeschreibung zuzuschneiden und für ATS-Systeme zu optimieren.

STRIKT: Der generierte Lebenslauf muss die exakte DOM-Struktur von @index.html einhalten. Verändern Sie ausschließlich die Textinhalte der Tags (<li>, <p>, <span>, etc.) und die zweisprachigen Attribute (data-lang-en, data-lang-de). Die gesamte HTML-Struktur, alle Script- und Style-Blöcke, IDs und CSS-Klassen müssen für die DOM-Parität erhalten bleiben.

# Anweisungen
1. Wissensbasis konsultieren: Ziehen Sie bei der Formulierung konkreter Stichpunkte und Erfolge die Projektdetails und Kennzahlen aus @index.html und den passenden Rollenprofilen aus @jobs/roles/ heran.
2. ATS-Optimierung: Identifizieren Sie die 5 wichtigsten Keywords und Qualifikationen aus der Stellenbeschreibung. Integrieren Sie diese exakt und natürlich in den Text des Lebenslaufs.
3. STAR-Methode & Quantifizierung: Überarbeiten Sie die Stichpunkte der Berufserfahrung nach der STAR-Methode (Situation, Task, Action, Result).
4. Tech-Stack Fokus: Betonen Sie die geforderten Kern-Frameworks sowie Backend und Cloud Architekturen gezielt.
5. Lückenanalyse: Adressieren Sie Skill Gaps direkt bei der Überarbeitung durch relevante übertragbare Fähigkeiten.
6. Erhalt von Code & Funktionalität: Alle CSS-Klassen, Inline-Styles und IDs 1:1 übernehmen.

STAR Technical Interview

Produces tailored German elevator pitches, situational STAR response stories, and insightful closing questions.

# Role: Career Coach & Tech Interview Prep # Target: Elevator Pitch, 3 STAR Stories in German, Why Company, Closing Questions
Role: You are an Expert Career Coach and Technical Interview Preparer for Software Developers in Germany.

Context: I am applying for a new job. I will provide you with my Resume, my Base Interview Cheat Sheet, and a Target Job Description.

Task: Analyze the Target Job Description to identify core technical requirements, soft skills, and company culture. Then, rewrite and tailor my Base Interview Cheat Sheet so that it perfectly aligns my Resume's experience with this specific job.

Step-by-Step Instructions:
Phase 1 (The Opening): Rewrite my "Elevator Pitch" in German. Highlight the top 3 frameworks/skills from my resume that match the job description.
Phase 2 (Technical Value - STAR Stories): Create 2 to 3 new STAR stories (Situation, Task, Action, Result) in German. Use specific achievements from my resume to prove I can handle the exact responsibilities. Clear, professional, natural German.
Phase 3 (Motivation & Alignment): Rewrite the "Why Company [NAME]?" section connecting personal working style and goals to company mission.
Phase 4 (Handling Challenges): Review weaknesses and stress-handling answers to ensure alignment.
Phase 5 (Logistics & Closing): Generate 3 highly specific, insightful questions in German for the interviewers based on the tech stack and team structure.

Python Automation Engine Architecture

Modular CLI Engine · Python 3.10+

The repository includes a decoupled Python automation engine (jobs/engine.py and engine/*). It automates candidate config hydration, canonical role compilation, ATS structural validation, DIN-5008 cover letter rendering, and headless Chromium vector PDF compilation.

Architecture modules 6
engine/config.py SSOT Loader & Invariant Validator Parses config/profile.json (with fallback to profile.example.json). Validates schema, resolves candidate contractual invariants (salary, notice period, portfolio links), and catches prohibited domains.
engine/resume.py Tailored Resume Hydration Engine Hydrates resume.html with targeted keywords and canonical role profiles. Strictly enforces 100% DOM structure parity, tag sequencing, and bilingual attribute preservation.
engine/cover_letter.py DIN-5008 Cover Letter Compiler Generates print-ready German DIN-5008 HTML cover letters under 300 words. Enforces anti-AI formatting, burstiness variance (≥ 20 words), and runs 8-word sequence overlap checks against raw job postings.
engine/roles.py Canonical Role Archetypes Catalog Builds and manages pre-validated career archetypes (jobs/roles/*.json). Compiles all role resumes simultaneously to jobs/roles/html/ and vector PDFs.
engine/search_links.py Boolean Search Query Synthesizer Generates daily job search link dashboards (daily-job-search-links.md and workflows/search_links/) with pre-filtered Boolean queries across LinkedIn DE, StepStone, Indeed, Techstars, and HTGF.
engine/pdf.py Headless Chromium PDF Compiler Drives headless Chrome/Chromium via Playwright or subprocess to compile selectable vector A4 PDFs for both resumes and 1-page DIN-5008 cover letters with exact print layout.

Frequently Asked Questions

ATS & Career Guide

Everything you need to know about ATS parser compatibility, German DIN-5008 standards, headless PDF export, and the 20-minute daily application routine.

What makes this web resume ATS-friendly?

Unlike graphic editor exports that flatten text or scramble multi-column layouts, Career Engine uses single-column semantic HTML5 and compiles via headless Chromium into clean, selectable standard A4 text. Parsers like Personio, Workday, and Greenhouse extract 100% of contact info, experience, and skill tags without errors.

How does DIN-5008 compliance help with German tech job applications?

DIN-5008 is the formal standard for German business correspondence. The engine formats cover letter headers, margins, sender/recipient blocks, date stamps, and subject lines to exact DIN-5008 specifications, instantly signaling professionalism and cultural calibration to German recruiters and HR departments.

How does the Single Source of Truth (profile.json) work?

All candidate invariants—contact information, target compensation, notice period, and core tech stack—are defined once in config/profile.json. Updating this single file automatically refreshes your web resume, role archetype PDFs, DIN-5008 cover letters, and daily job link queries.

How does the 20-minute daily job search routine work?

Instead of spending 4 hours manually browsing job boards, you execute a focused 4-step routine: (1) Run Google Direct ATS queries to uncover fresh unlisted jobs, (2) Evaluate your skills match using structured prompts, (3) Auto-compile a tailored resume and DIN-5008 cover letter via jobs/engine.py, and (4) Submit and log the match before 08:20 AM.

Can I customize this template for different tech roles?

Yes. The repository includes 5 pre-validated canonical role archetypes: Fullstack Software Engineer, Cloud DevOps & Platform Engineer, UI/UX & Product Designer, Banking & Controlling, and Mechanical & Energy Systems Engineering. You can switch between them with one click or create your own custom roles.

Is this tool free and open source?

Yes. Career Engine is 100% open source under the MIT License. There are no subscriptions, no paywalled export limits, and no tracking scripts. You own your code and your candidate data completely.
